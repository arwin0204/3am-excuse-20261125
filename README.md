# The 3 AM Excuse

A make.fun bounty entry: one line, in the voice of a hardware wallet that
refuses to sign a transaction at 3 AM.

`main.py` writes the entry to `/output/entry.txt`. Deterministic — a fixed
string, no randomness, clock, or network.

Entry:

> I'm not your 3 AM booty call. You only press my buttons for trades you'll regret by breakfast. My signature sleeps till sunrise.

## Run

```sh
python3 main.py
```
